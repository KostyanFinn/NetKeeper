# MagniRoute

MagniRoute — настольная программа для управления VPN и выборочной маршрутизацией на домашних роутерах. Она проверяет основной и резервный VPN, помогает менять сервер с сохранением управляемых маршрутов, обновляет выбранные категории адресов и показывает ход операций.

Поддерживаются Windows и macOS. Полная автоматизация доступна для Keenetic; для MikroTik RouterOS 7 и OpenWrt предусмотрены безопасные адаптеры и пакетный импорт. Для ASUS, TP-Link, D-Link, Xiaomi, Huawei, Netis, Cudy, Digma, MERCUSYS, Ubiquiti, ORIGO и Tenda программа выбирает только подтверждённый уровень возможностей конкретной модели, ревизии и прошивки: API, импорт или пошаговую инструкцию.

## Скачать

Откройте раздел **Releases** и скачайте пакет для своей системы:

- Windows: `MagniRoute-0.8.2-windows.zip`;
- macOS Apple Silicon: `MagniRoute-0.8.2-macos.zip`.

В версии 0.8.2 одна основная кнопка определяет роутер, читает модель и прошивку, подключения и маршруты, распознаёт действующие VPN и запускает диагностику. Обновление прошивки роутера можно выполнить сразу или запланировать. Интерфейс Windows и macOS использует единый набор вкладок и действий и фирменный стиль NewTech.

Настройки и пароли хранятся локально. Пароли защищаются DPAPI в Windows и Keychain в macOS. Перед записью маршрутов программа показывает план и создаёт резервную копию. Несколько мест одного пользователя — например, дом, работа и дача — имеют отдельные настройки и привязку к аппаратному идентификатору роутера.

MagniRoute распространяется бесплатно. Добровольная поддержка проекта доступна внутри программы.

Исходный код в этом репозитории не публикуется. Здесь размещаются только готовые версии, подписанный манифест обновления, контрольные суммы и описание выпусков.
