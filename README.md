# NetKeeper

NetKeeper — настольная программа для управления VPN и выборочной маршрутизацией на домашних роутерах. Она проверяет основной и резервный VPN, помогает менять сервер без потери маршрутов, обновляет выбранные категории адресов и показывает ход каждой операции.

Поддерживаются Windows и macOS. Полная автоматизация доступна для Keenetic; для MikroTik RouterOS 7 и OpenWrt предусмотрены безопасные адаптеры и пакетный импорт, для других марок — профили настройки и экспорт по возможностям прошивки.

## Скачать

Откройте раздел **Releases** справа и скачайте пакет для своей системы. Windows-пакет содержит готовый `NetKeeper.exe`. Пакет macOS публикуется только после нативной сборки и подписи на Mac.

Настройки и пароли хранятся локально на компьютере пользователя. Пароли защищаются DPAPI в Windows и Keychain в macOS. Перед первой записью маршрутов программа показывает план и создает резервную копию.

NetKeeper распространяется бесплатно. Добровольная поддержка проекта доступна внутри программы.

Исходный код в этом репозитории не публикуется. Здесь размещаются только готовые версии, контрольные суммы и описание обновлений.
