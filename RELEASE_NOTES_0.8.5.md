# MagniRoute 0.8.5 beta

- Исправлено ложное предложение обновить прошивку, когда установленная и доступная версии совпадают.
- Восстановлены понятные значки видимости пароля: 🙈 скрыт, 🐵 показан.
- Кнопки получили более мягкие оттенки и скругление; основные действия остаются видимыми при небольшом окне.
- Новый значок приложения сочетает цвета NewTech и силуэт роутера на Windows и macOS.
- Улучшено объединение мест одного пользователя между устройствами. Экран входа теперь предлагает ввести одноразовый код из письма.

Сервер учётных записей и оплата ещё не включены в общедоступной сборке. Их настройка требует отдельного размещения API, почты и платёжных реквизитов.
