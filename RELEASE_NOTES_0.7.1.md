# NetKeeper 0.7.1

Переходный релиз повышает надёжность доставки и установки обновлений приложения.

## Онлайн-обновление

- Манифест проверяется подписью Ed25519 до извлечения версии и адреса пакета.
- Пакет загружается только по HTTPS, с ограничением размера до 300 МБ, проверкой Content-Length и SHA-256.
- Краткие сетевые сбои повторяются; корректный частичный файл `.part` продолжается только после точного ответа HTTP 206 с `Content-Range`. Финальный архив появляется атомарно после полной проверки.
- При следующем запуске сохранённый манифест и архив проверяются заново. Изменённый, повреждённый или устаревший кэш удаляется из `UserData/updates`.

## Windows recovery

- Перед заменой файлов создаются durable-журнал и снимок последней рабочей версии.
- Новая копия запускается с `--self-test`; при ошибке или прерывании выполняется откат.
- Во время операции в `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run` временно остаётся помощник `NetKeeper Update Recovery`. Он выводит пути из своего staging-каталога и проверенного журнала, не принимает пути из автозапуска.
- Помощник удаляется после terminal journal state. Если компьютер выключился раньше, восстановление повторяется при следующем входе пользователя.

## macOS

Нативная `.app` по-прежнему собирается только на Mac. Перед передачей пользователю нужно выполнить `bash build-macos.command`, пройти тесты и запуск `.app`, проверить Keychain и доступ к локальной сети. Онлайн-пакет открывается в Finder; пользователь закрывает NetKeeper, заменяет `.app` вручную и сохраняет каталог `~/Library/Application Support/NetKeeper`. Для распространения без предупреждений Gatekeeper нужны Developer ID и нотариализация Apple.

Windows-пакет прошёл автоматические тесты, автономную самопроверку EXE и сетевую проверку источников обновлений. Публичный macOS-пакет появится только после отдельной нативной сборки и приёмки на Mac.
