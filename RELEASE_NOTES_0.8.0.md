# MagniRoute 0.8.0

- Новое имя программы: MagniRoute. Обновление с NetKeeper 0.7.x сохраняет настройки и совместимость автозапуска.
- Добавлены независимые места «Дом», «Работа», «Дача» и другие: у каждого свои роутер, маршруты, VPN, расписание, журналы и резервные копии.
- Роутер привязывается по защищённому отпечатку аппаратного идентификатора. Несовпадение блокирует изменение маршрутов и VPN до записи на устройство.
- Добавлена защита от установки одного клиентского WireGuard-профиля на несколько роутеров.
- Расширена матрица производителей и безопасный экспорт для ASUS, TP-Link, D-Link, Xiaomi, Huawei, Netis, Cudy, Digma, MERCUSYS, Ubiquiti, ORIGO и Tenda.
- Добавлена отдельная кнопка покупки VLESS через VPNReal. Покупка hide.my.name остаётся отдельной.
- Улучшены фоновая проверка всех мест, восстановление после сбоев и защита хранилища.
- Исправлена проверка состава macOS-пакета; приложение собрано и проверено на нативном macOS arm64 runner.

Проверено: 217 автоматических тестов, self-test Windows EXE, self-test macOS `.app`, проверка TLS/HTTPS, подписи манифеста, SHA-256 и отсутствия исходников или пользовательских данных в публичных архивах.
