# MagniRoute 0.8.3 beta

## Что исправлено

- На вкладке hide.me / WireGuard появилась постоянно видимая кнопка **«Проверить основной и резервный VPN»**.
- Ручная проверка обновляет состояние обоих настроенных туннелей через HTTPS и сразу показывает свежий результат в таблице.
- Недоступность одного VPN больше не прерывает проверку второго: отрицательный результат сохраняется с актуальным временем.
- Подробное сравнение нескольких VPN осталось в меню **«Дополнительно»**, чтобы основной экран был проще.

## Проверка выпуска

- Выполнены 224 автоматических теста.
- Windows-сборка проходит встроенный self-test и сетевую TLS-проверку.
- Публичные ZIP-пакеты не содержат исходников, `UserData`, паролей или локальных настроек.
- `update.json` подписывается Ed25519; размер и SHA-256 каждого пакета проверяются до установки.

## Ограничения

- Полное управление VPN и маршрутами доступно для Keenetic. Поддержка остальных брендов зависит от их официальных API и описана в интерфейсе без ложного обещания полной автоматизации.
- На macOS загруженный проверенный архив заменяется пользователем вручную.
- Облачная синхронизация между компьютерами и мобильные приложения Android/iOS в этот выпуск не входят.
